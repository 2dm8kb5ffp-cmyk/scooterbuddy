# ScooterBuddy prototype v1.0

## Inhoud
- index.html: de app
- manifest.json: installeerbare webapp metadata
- sw.js: eenvoudige offline cache

## Testen
Open index.html in een browser om de app te testen. Voor installatie als PWA op iPhone/Android moet de app via HTTPS worden gehost. GitHub Pages kan dit gratis.

## Belangrijk
- Gegevens worden lokaal opgeslagen in de browser (localStorage).
- Geen accounts, cloudsync, betaalfunctie of echte pushmeldingen in deze prototypeversie.
- Maak regelmatig een back-up via Instellingen.
- Dit is een prototype, geen vervanging voor een professionele onderhoudshandleiding.
